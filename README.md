# Greeting Cards PWA

A small mobile-first Progressive Web App built with pure HTML, CSS, and JavaScript. The project includes a Python scraper for collecting the greeting-card dataset, a CSV-based data source, category filtering, random cards, sharing, and offline-friendly PWA caching.

The project is also documented as a step-by-step book covering the complete development process, from web scraping and frontend development to deployment and PWA installation.
